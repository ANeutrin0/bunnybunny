# BunnyBunny

Every bunny needs a buddy. 给每只小兔，找个刚刚好的伴。

一个以小兔舞会为主题的休闲逻辑解谜游戏，包含 50 个关卡、五章地图、小兔衣橱和成就收藏，支持电脑和手机。

## 游玩

每个分区恰好安排两只小兔；每只小兔与上下左右相邻的另一只组成舞伴，可以跨分区配对。× 是可选的排除笔记。

游戏支持撤销、一键清空和分步提示。进度保存在当前浏览器中，不同设备或网址之间不会自动同步。

## 单文件版本

`index.html` 包含游戏全部画面、样式、关卡、逻辑和合成音效，无需安装依赖。下载后可直接用浏览器打开，也可作为单个 HTML 提交。

界面语言：简体中文。
